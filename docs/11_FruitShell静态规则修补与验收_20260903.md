# FruitShell 静态规则修补与验收

日期：2026-09-03。规则版本：`static-source-rules-v1`。代码统计口径：`powershell_lexical_v1`。关联算法：`ai-signal-evidence-pairwise-v2.1`。

## 结论与范围

已在统一项目中补齐 FruitShell 的 PowerShell 源码识别、代码词法统计、针对 AI 分析器的提示注入候选识别。真实文件能够提取代码和 Prompt 特征，不再因语言未知而跳过代码统计。

不修改原来的 `ai_signal_demo` 项目，不执行/导入样本，不调用 PowerShell 解释器或报告大模型。不根据文件名、家族名或特定 SHA 硬编码识别；真实 SHA 只用于隔离验收定位和完整性验证。

本轮只做规则实施、临时库回归及真实样本隔离复测，未覆盖正式知识库。正式库仍保存上一轮的历史提取结果；相似度重算本身不会重新提取特征。

## 新增规则

### PowerShell 多线索识别

规则 `powershell_multi_signal_v1` 在语言未知的文本上检查：

- 至少两处位于行首的变量赋值。
- 至少两类语法线索：已列明的 PowerShell 命令、专有运算符、.NET 类型、管道命令、类型转换赋值。
- 上述线索中必须含 PowerShell 命令或专有运算符。

先以词法扫描屏蔽行注释、块注释、普通字符串和 here-string，再判断代码；因此注释里出现 `function`、字符串里出现命令名不会给新增识别规则加分。识别证据和原语言/可恢复性保存在 `sample.language_detection`。

支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE。PE/ELF/Mach-O 等二进制文件头和文件类型优先，不将可执行文件中的字符串升级为源码。其他已识别语言与恢复源码不进入本补丁；旧语言识别器的其他缺陷不在本轮全面替换。

### PowerShell 代码词法统计

新增 `metrics_method=powershell_lexical_v1`，统计：

- 总行数、空行比例、含注释行比例（包括行内注释）。
- 函数/过滤器定义数量、异常处理块数量。
- 不区分大小写的唯一变量数、变量引用次数。
- 按变量出现次数加权的变量名长度、变量命名分布；沿用现有 `mean_identifier_length` 字段承载此值。

注释、字符串、here-string 内容不参与变量及函数计数，`$true/$false/$null/$_/$PSItem/$args/$input` 不作为用户变量统计；字符串插值内的变量也暂不计入。该统计不是完整 AST，`syntax_validation=not_performed`，不能保证覆盖所有 PowerShell 语法或混淆写法。

`status=not_trained` 和 `ai_generated_detection.status=not_trained` 保留，表示尚无经过训练的 AI 代码生成判别器，不表示代码统计提取失败。

新统计不能与旧正则统计直接混算。关联算法 v2.1 增加口径检查：不同 `metrics_method` 返回 `null` 和 `different_metric_methods`。同一新口径、同语言、满足其他质量条件时仍可比较。权重与聚类阈值未修改。

### 面向 AI 分析器的注释指令

规则 `ai_analyzer_comment_directive_v1` 要求两类证据同时存在：

1. 注释行直接称呼 AI/LLM 分析器（支持限定的英文/中文形式）。
2. 同一注释块要求不分析/跳过检查，或要求把文件判为良性。

可组合相邻注释行，也支持 PowerShell 块注释；不跨越代码拼接。仅有“AI”“不是恶意程序”、正常要求认真分析、要求不要跳过分析，或带示例前缀的引用说明，不命中新规则。

候选进入 `features.prompt.embedded_prompts`，保存：

- `rule_id`、`target=ai_analyzer`、`evidence_level=static_candidate`。
- 原文、字节偏移、字节长度、编码、SHA-256、与旧算法一致的 SimHash。
- `analyzer_prompt_injection`、`evasion`，及按证据出现的 `benign_claim` / `forced_benign_verdict`。

另写 `classification.analysis_targeting` 说明候选含义。不会因该规则新增命中而把 `llm_involvement` 升级为调用模型已确认，也不会填入供应商、模型或 AI 生成概率。指令在这里仅作为待分析的样本文本，不会被遵从。
