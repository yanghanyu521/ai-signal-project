# v0.8 对 45 个样本的重新分析与规则基线对比

## 范围和口径

2026-10-08 对原有 9 个家族、45 个相同 SHA-256 的恶意样本进行了隔离静态复测。新结果使用 v0.8 样本分析路径与 DeepSeek v4（远端脱敏策略），旧基线采用 2026-09-20 批次留存的 `old_rule_result.json`，不是旧版 LLM 结果。没有执行样本、写入正式知识库或运行 Docker。结果中的工具链和 Prompt 数字是**候选记录数**，不能直接解释成识别准确率、已验证调用数或新增事件数。

逐样本完整结果保存在本机 `data/evaluations/20261008_all45_v08_full/`，包括运行清单、两版结果、逐样本差异、分组表、文字报告和质量审计。该目录含从恶意样本提取的内容，按项目 `.gitignore` 不上传公开仓库。仓库中提供可续跑的 `scripts/compare_v08_all45.py`、汇总脚本 `scripts/summarize_v08_all45.py` 和校验脚本 `scripts/audit_v08_all45_results.py`。

## 主要差异及局限

1. **脚本源码：**候选记录增多，但有工具链/Prompt 的样本数未增加。v0.8 多了 22 个文件级、110 个局部确定性文体指纹；旧规则版 23 个脚本均有描述性代码统计，两者指标与资格门槛不同，不宜直接计算“提升率”。
2. **可执行与封装样本：**工具链记录 23→42，Prompt 记录 29→33，但有 Prompt 的样本从 10 降至 8。缺失集中在两份 LAMEHUG PE（`bdb33bbb4ea1`、`d6af1c9f5ce4`）：旧 Prompt 来自 `image.pyc` 经 `pycdc` 恢复的字符串。全量运行时本机没有 `pycdc`，没有实际反编译；之后已关闭旧 PyInstaller 解包/反编译开关，并对这两份独立复测，工具链与 Prompt 候选数量不变。7 个 PromptSpy APK 中有 6 个在本次仍无工具链或 Prompt 候选，反映受限字符串路径的覆盖范围，不能据此推断没有 AI 行为。
3. **文体语义误分：**105 条 LLM 文体观察虽然全部有原文锚点，但自动复核标记出至少 15 条 `dialogue_residue` 与应用 Prompt 重叠、3 条 `generation_claim` 没有明确的 AI 生成代码声明。它们保留在原始产物中供复核，不应当作可靠的代码生成特征。另有 11 条旧式 `code_observation` 只作历史审计，不参与新指纹。

现有 45 个恶意样本缺少可靠的代码生成模型来源标签，不能用本次结果宣称 AI 代码识别率、具体生成模型归因准确率或模型版本识别能力。下一步优先人工复核新增/缺失的工具链与 Prompt 候选、收紧 LLM 文体标签的语义门禁，并为受限二进制路径定义可接受的覆盖目标。现有 A–K 合成评估的二进制用例使用历史保存的反编译导出，不代表 v0.8 会运行反编译。
