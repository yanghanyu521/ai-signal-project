# AI 信号静态提取评测说明

## 1. 评测目的

自动化测试用于防止代码回归，评测集用于观察提取质量，两者不能互相替代。`evaluation/` 中的 A—K 共 11 类夹具全部为无害合成内容或保存的无害反编译导出，覆盖已知正例、词典外模型、私有端点、诱饵、依赖、example、分析器定向指令、动态 Prompt、wrapper、多模型和二进制/反编译关系。

每个用例在 `evaluation/annotations/cases.json` 中人工标注预期模型、工具链、Prompt 组成部分、强负例、角色或关系数量。运行器调用项目真实静态适配入口；默认关闭远端 LLM 和 Docker，不执行输入文件。K 类直接回放保存的 Ghidra JSONL，以验证函数调用和字符串引用是否解析为真实单元关系。

## 2. 指标

运行结果包含：

- 模型标识 precision / recall；
- 模型厂商错误归因率；
- Prompt 组成部分 precision / recall；
- Prompt 调用绑定 precision；
- decoy 误报率、role 错误率；
- 引用有效率、关系验证 precision、分析失败率；
- 平均请求数、token 和本地耗时。

分母为 0 的指标输出 `null`，不伪造 0 或 100%。默认基线关闭 LLM，因此平均请求数和 token 为 0；模型厂商无预测时，厂商错误归因率为 `null`。耗时受主机影响，不设固定阈值。

## 3. 当前本地基线

2026-09-18 使用项目 `.venv` 运行 11 个用例：模型标识 precision/recall、Prompt 组成 precision/recall、Prompt 调用绑定 precision、引用有效率和关系验证 precision 均为 1.0；decoy 误报率、role 错误率和分析失败率均为 0.0。模型厂商错误归因率为 `null`，因为这组用例没有产生模型厂商预测。该结果只说明当前无害合成集全部符合标注，不能外推为真实恶意样本总体准确率。

## 4. 运行与扩展

```powershell
.\.venv\Scripts\python.exe .\evaluation\run_eval.py --output .\evaluation\latest_metrics.json
```

增加用例时必须同时提交夹具与人工标注，不得仅增加“期望通过”的代码断言。真实模型评测应记录模型、端点、外发策略、请求/token/耗时和失败，使用 `httpx.MockTransport` 的普通 CI 不替代真实服务评测。真实恶意样本不得提交仓库，必须在授权隔离环境中评测。
