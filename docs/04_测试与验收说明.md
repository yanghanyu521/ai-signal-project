## 人工验收流程

1. 在 API 进程环境配置模型密钥，启动 API，访问 `/api/v1/health` 和 `/docs`，确认版本 0.3.0。
2. 启动 Streamlit，确认全局看板可连接 API。
3. 点击“导入旧项目数据”，确认全球事件为 25、可分析事件为 9、无样本事件为 16、样本为 45、家族为 9；数据库事件记录单列说明。
4. 在“联合分析”页只上传 `ai_signal_demo/tests/fixtures/sanitized/promptflux.txt`，确认状态为 `waiting_for_report`。
5. 选择同一案例补传 `报告信息抽取/tests/fixtures/promptflux_report.html`，目标填写 `PROMPTFLUX`，确认状态变为 `ready_for_review` 并产生自动验证与联合摘要。
6. 在“样本关联”页查看聚类、工具链/Prompt/代码文体分项相似度和共同特征。
7. 在交叉验证页先选择案例，确认只能选择案例内样本/报告；检查具体提示词、中文特征名及组织/国家/地区，并尝试保存人工修订后刷新复核。
8. 在知识库页按 `Gemini`、`PROMPTFLUX` 和样本哈希检索。
9. 在生成报告页选择一个不包含当前数据的历史范围，确认范围统计为零；再生成全库报告并核对看板。
